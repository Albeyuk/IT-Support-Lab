# IT Support Lab

## Overview
This repository is a hands-on lab for IT Support and Systems Administration. It includes scripts and guides to demonstrate key sysadmin tasks, inspired by Level 3 Cyber Security labs.

## 🔧 Skills Covered
- Active Directory user and group management
- Windows/Linux patching and updates
- Backup and restore automation
- Basic network monitoring and troubleshooting
- Secure configuration (Windows & Linux)
- Vulnerability assessment labs (DVWA & Kali)

## 🗂 Repository Structure
- `scripts/` → PowerShell and Python scripts for common IT tasks
- `labs/` → Step-by-step lab setups (AD Lab, DVWA/Kali lab)
- `screenshots/` → Example outputs and visual guides
- `docs/` → Security hardening and configuration guides

## ⚡ Example Scripts
1. **create_users.ps1** → Bulk create users in Active Directory from a CSV
2. **patch_check.ps1** → Check and log missing Windows updates
3. **backup_automation.ps1** → Backup directories to a secure location
4. **network_monitor.py** → Monitor network connectivity and services

## 📌 Usage
- Clone this repo
- Follow lab guides in `labs/`
- Run scripts in a safe lab or test environment
